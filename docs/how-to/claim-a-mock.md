# How to keep a mock by signing up

Use this when you created an anonymous mock and want it to stay permanently.

1. Create the mock in the chat. Do **not** refresh the page afterwards.
2. In the mock's card, click **Sign up** (or use the button in the header).
3. Enter your email and a password of at least 8 characters, then click **Create account**.
4. The bot confirms: "Your mock is now permanent."

The mock keeps its URL. It is now owned by your account and no longer expires.

## If you already refreshed the page

The page only remembers the mock in memory, so after a refresh it can no longer be attached to a new account. Create the mock again, then sign up. This is intentional; see [The anonymous expiry model](../explanation/anonymous-expiry.md).

## If the confirmation says the mock was not kept

The mock had already expired or been claimed by another account. Create it again while signed in; mocks you create while signed in are permanent.

## See all your mocks

Sign in and click **My mocks** in the header.
