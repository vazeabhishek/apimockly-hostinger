# Reference: mock URL scheme and serving rules

## URL

```
{PUBLIC_BASE_URL}/m/{id}{path}
```

- `id`: 12 random characters from `a-z0-9`, generated by the server.
- `path`: the path given in the chat phrase, exactly as written.

## Matching

A request is served only if **all** hold:

1. A mock with this `id` exists.
2. The HTTP method equals the mock's method.
3. The request path after `/m/{id}` equals the mock's path exactly (case-sensitive; trailing slash matters; the query string is ignored).
4. The mock has not expired (`expires_at` is `NULL` or in the future).

## Responses

| Situation | Status | Body |
|---|---|---|
| Match | Mock's status (default 200) | Stored JSON body |
| Any of conditions 1–4 fails | 404 | `{"error":"No mock matches this request."}` |
| Rate limit exceeded | 429 | Rate limiter error body |

204 and 304 mocks are returned with an empty body. The request body and headers are ignored.

## Headers on every response from `/m/*`

| Header | Value |
|---|---|
| `Content-Type` | `application/json; charset=utf-8` |
| `X-Content-Type-Options` | `nosniff` |
| `Content-Security-Policy` | `sandbox` |
| `Cache-Control` | `no-store` |
| `X-RateLimit-*` | Current limiter state |
